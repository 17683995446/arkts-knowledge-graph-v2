模块说明

📁 file_watcher.py

文件监控模块，基于watchdog库实现。支持防抖机制，仅当文件停止修改1秒后才触发更新。

🧠 llm_parser.py

LLM解析模块，调用硅基流动API解析ArkTS代码，提取实体、关系和导入语句。

💾 knowledge_graph_db.py

数据库管理模块，使用SQLite存储文件指纹、代码实体和关系数据。

⚙️ knowledge_graph_service.py

核心服务模块，协调文件监控、代码解析和数据库更新。

🌐 web_server.py

Web服务器模块，提供REST API和WebSocket实时通信。

核心算法流程

1

检测变更

file_exists_and_unchanged(path, content)

计算文件SHA256指纹，与数据库中存储的指纹对比

2

删除旧数据

delete_file_data(file_path)

级联删除该文件的所有实体、关系、导入记录

3

LLM解析

parser.parse_file(path, content)

调用硅基流动API，使用Qwen2.5-Coder模型解析代码

4

插入新数据

add_entity(), add_relationship()

将解析结果写入数据库，建立新的知识图谱

时序图

sequenceDiagram
    actor User as 用户
    participant FW as FileWatcher
    participant KG as KnowledgeGraphService
    participant DB as SQLiteDatabase
    participant LLM as SiliconFlow API
    participant WS as WebSocket
    participant UI as Web UI

    User->>FW: 修改 ArkTS 文件
    activate FW
    FW->>FW: 防抖等待 1 秒
    FW->>KG: 触发文件变更事件
    deactivate FW

    activate KG
    KG->>DB: 查询文件指纹
    activate DB
    DB-->>KG: 返回旧指纹
    deactivate DB

    KG->>KG: 计算新指纹
    KG->>KG: 对比指纹

    alt 内容已改变
        KG->>DB: 删除文件旧数据
        activate DB
        DB-->>KG: 确认删除
        deactivate DB

        KG->>LLM: 发送代码解析请求
        activate LLM
        LLM-->>KG: 返回实体/关系/导入
        deactivate LLM

        KG->>DB: 插入新实体记录
        activate DB
        KG->>DB: 插入新关系记录
        KG->>DB: 插入新导入记录
        DB-->>KG: 确认插入
        deactivate DB

        KG->>DB: 记录更新事件
        activate DB
        DB-->>KG: 确认
        deactivate DB

        KG->>WS: 广播更新消息
        activate WS
        WS->>UI: 推送更新通知
        deactivate WS
        deactivate KG

        activate UI
        UI->>UI: 刷新知识图谱
        UI-->>User: 显示更新结果
        deactivate UI
    else 内容未改变
        KG-->>KG: 跳过更新
        deactivate KG
    end
