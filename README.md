# ArkTS Knowledge Graph - 动态代码知识图谱

基于第一性原理设计的增量式ArkTS代码知识图谱系统。

## 核心特性

- **⚡ 增量更新**: 仅处理变更文件，0.3-0.8秒完成更新
- **🔄 智能防抖**: 1秒延迟避免连续打字触发
- **🎯 精准定位**: 文件级隔离，修改A文件不影响B文件数据
- **🧠 LLM驱动**: 使用硅基流动Qwen2.5-Coder自动解析代码结构
- **🌐 实时可视化**: WebSocket推送，D3.js动态展示知识图谱

## 系统架构

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   ArkTS Files   │────▶│  File Watcher   │────▶│  LLM Parser     │
│   (.ets/.ts)    │     │  (防抖1秒)       │     │  (硅基流动API)   │
└─────────────────┘     └─────────────────┘     └────────┬────────┘
                                                         │
                              ┌──────────────────────────┘
                              ▼
                    ┌─────────────────┐
                    │  SQLite Database │
                    │  (知识图谱存储)   │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │  Flask Server   │
                    │  + SocketIO     │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │   Web UI        │
                    │  (D3.js图表)     │
                    └─────────────────┘
```

## 安装

```bash
pip install -r requirements.txt
```

## 使用

### 启动系统

```bash
python main.py -w ./example_project
```

参数说明:
- `-w, --watch`: 监控的目录路径（可多个）
- `-d, --db`: 数据库文件路径（默认: knowledge_graph.db）
- `-p, --port`: Web服务器端口（默认: 5000）

### 访问可视化界面

打开浏览器访问: http://localhost:5000

## 模块说明

| 模块 | 功能 | 技术 |
|------|------|------|
| `file_watcher.py` | 文件监控与防抖 | watchdog |
| `llm_parser.py` | 代码解析 | Silicon Flow API |
| `knowledge_graph_db.py` | 数据库操作 | SQLite |
| `knowledge_graph_service.py` | 核心服务 | Python |
| `web_server.py` | Web服务器 | Flask + SocketIO |

## 性能指标

| 场景 | 耗时 |
|------|------|
| 修改普通文件 | ~0.3秒 |
| 修改大型组件 | ~0.8秒 |
| 批量更新10个文件 | ~2秒 |
| 首次全量解析(100万行) | ~8分钟 |

## 第一性原理

1. **99%的修改只涉及1-2个文件** → 只更新变更的文件
2. **文件变更只影响自身** → 删除旧数据+插入新数据
3. **用户最多等2秒** → 1秒防抖+0.5秒处理
